Pool grades

The app-hosted pool (desktop child process, loopback, JSONL on disk) is for friends, family, LAN, and mesh. One process, no HA, no RDS-style backups. If the process dies or the file is lost, some accepted work can vanish from the TIDES window. With people you know, you can make that right. At scale (strangers, public hashrate, mainnet) it is an incident.

A pro pool needs a shared share store (Postgres), replicas only after that store exists, and backups. Sticky sessions are not TIDES. Templates: infra/k8s/federationcoin/values-pool-ha.yaml and infra/cloudformation/pool-rds.yaml. Do not apply RDS onto the current demo cluster unless you mean to.

Node and mempool databases can stay cheap. If other peers still hold the chain, a wiped node can IBD. Mempool MariaDB is a cache. Pool shares cannot be recovered from P2P.

This house pool

The EKS testnet deploy is a demonstration piece, not the pool of record. MAIN is not served. Config is in the image / ConfigMap, not edited here.

DATUM is bring your own node

The pool DATUM port is the coinbaser. Template construction stays on your bitcoind. This cloud UI will not proxy our node (that would defeat DATUM). Supported path: desktop app + your node + TCP DATUM to the advertised pool host.

Explore (not implemented): a JSON-RPC-over-WebSocket spec for your node, then a separate RpcConnectWs partition. A browser could combine pool WSS /datum with that node URI. Until a spec exists, there is no live URI box. Pool WSS /datum is the coinbaser wrap only.

WebSocket Stratum

The web SPA is mine.federationcoin.org (network is the in-app dropdown). In-page mining uses wss://pool.testnet.federationcoin.org/stratum (same jobs as TCP 23334). Native miners keep TCP. Third-party Stratum from the browser also needs a WebSocket endpoint.
